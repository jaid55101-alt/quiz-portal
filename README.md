# 🎯 Quiz Portal

Welcome to **Quiz Portal**! A simple and interactive quiz website built using HTML, CSS, and JavaScript.

## 📌 About the Project

Quiz Portal is a web-based application designed to make learning fun and interactive. Users can answer multiple-choice questions and check their quiz scores.

## ✨ Features

* 🎨 Attractive UI with gradient background
* ❓ Multiple-choice questions
* 📊 Score tracking
* ⚡ Interactive user interface
* 📱 Responsive design
* 💻 Simple and user-friendly layout

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **JavaScript** – Quiz functionality and logic

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using the Quiz Portal!
